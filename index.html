Recent Works

This project is a private, self-hosted alternative to Google Drive, designed for effortless deployment using Docker and Traefik. It prioritizes simplicity, functionality, and complete control over data and security, offering a robust solution for personal file storage.

Pichola is an award-winning game created during a Game Jam, where it earned the prize for 'Best Art'. The game embodies the theme "Start from Nothing." Players begin as an egg, collecting other eggs across the map to unlock abilities like jumping, double-jumping, and wall toggling. Future plans include adding new levels and sharing the game with a wider audience.

This project reimagines the classic Parchís game with a strategic twist. Players alternate between two colors each, and while controlling both, they can still attack their own pieces, adding an extra layer of strategy. The goal is to get all pieces of one color to their destination square. The project focuses on implementing a deliberative AI agent using MINIMAX or ALPHA-BETA PRUNING, enabling intelligent gameplay and allowing the AI to compete effectively against human players.

Cypher is a state-of-the-art encrypted chat application that prioritizes user privacy and security. With end-to-end encryption, real-time messaging, and zero metadata storage, it ensures complete anonymity and peace of mind. Key features include secure group chats, cross-platform support, and advanced encryption protocols like TLS and Signal. Cypher’s architecture safeguards all data through AES encryption and stores no user-linked information, making it a truly private communication platform.

Visual Path Finding is an interactive tool that demonstrates how various path-finding algorithms operate. It provides a creative and intuitive way to understand the mechanics of algorithms like A*, Dijkstra, and more. This project serves as both an educational resource and a platform for refining algorithmic implementations.

This project focuses on classifying mushroom edibility using supervised machine learning models. As part of the 'Aprendizaje Automático' course at the University of Granada, the project analyzes the Secondary Mushroom dataset from the UCI Machine Learning Repository.

SolarSystem-Simulation is a Python-based simulation of a solar system featuring gravitational pull and collision dynamics, including interactions with asteroids. Built using pygame, it offers an engaging way to explore basic celestial mechanics.
